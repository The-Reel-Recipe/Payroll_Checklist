# Payroll Checklist — Handoff

**What this is:** an interactive checklist for running the monthly payroll close, for HR.
Open **`index.html`** in any browser (double-click). Works offline, on Mac or
Windows. Tap a step to see the how-to; tap the circle on the right to check it off.
Progress saves in that browser. Ctrl / ⌘ + P prints it.

Last updated **2026-08-30**.

---

## The run — 10 steps, 3 phases

**Before the run (last day or two)**
1. **Everything's approved** — managers approve OT / Leaves / KPIs (HR only checks & chases, in *My Team*); **HR** approves the *Bonuses, advances & penalties* page.
2. **Set up the Working Days Calendar** — holidays, closures, late-opening grace.
3. **Check every leaver's exit date** — set *Termination Date* first, **then** tick *Contract Terminated*.
4. **Import the attendance** — open the **TRR Attendance** page, click **Update attendance**.

**Generate the payslips (when the check says ready)**
5. **Tick the box to generate** — on the **Run Payslips** page, read *Payslip Readiness*. 🟢 "Inputs ready" → tick *Generate Payslips Now*. 🔴 → it lists what's missing (OT pending, KPIs not generated…); fix, and it goes green on its own. After it runs, the box **unticks itself**.
6. **Read the card check & everyone has a payslip** — read *Card Check Result* on the same row. ✅ "All clean" → done. ⚠ → it names who to fix (no salary card / attendance not imported); fix them, **re-tick** the box, re-read. Then confirm everyone has a payslip.
7. **Clear every blocker** — set a payslip to *Under Review*; a problem one turns *Blocked* and shows what's wrong. Fix the cause; it clears itself.
8. **Totals look right** — quick look down Net Pay.

**Approve & pay (one-way — the point of no return)**
9. **Approve** — freezes the figures (snapshot). Nothing is sent yet.
10. **Mark Paid** — emails the employee their breakdown. Only after the money is actually out.

## Key facts baked into the wording (don't undo these)

- **HR works only from the Interface**, never the raw data tables.
- **Leaves & KPIs** are approved by managers in **My Team**, not in the Payroll interface.
- **The attendance importer is a web page** ("TRR Attendance") with an **Update attendance** button — not a double-click tool, and not "Import to Airtable".
- **Payslips are generated by ticking a box, not automatically.** On the **Run Payslips** page, HR reads *Payslip Readiness*, then ticks **Generate Payslips Now**. The box unticks itself when it finishes, and re-ticking is always safe (never duplicates, never touches an approved payslip).
- **Two checks, in order: readiness *before* the tick, card check *after*.** *Payslip Readiness* pre-checks only the month-linked inputs (overtime, adjustments, KPIs). The salary-card / attendance problems can only be found *after* generation, so the script writes them into **Card Check Result** as plain-English names — HR never reads run logs.
- **A payslip only reveals its blockers after it's set to Under Review.**
- **Termination: date first, then the tick** — ticking with an empty date stamps today.
- The payslip **email is what "Paid" sends** — for the first live month it's switched on last.
