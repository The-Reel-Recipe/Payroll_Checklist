# Payroll Checklist

An interactive, offline checklist for running **The Reel Recipe's** monthly payroll close, for HR.

## Use it

Open **[`index.html`](index.html)** in any browser (double-click). Works offline, Mac or Windows.

- **Tap a step** to see the how-to.
- **Tap the circle** on the right to check it off.
- Progress saves in that browser. Press **Ctrl / ⌘ + P** to print.

## The run — 10 steps, 3 phases

**Before the run**
1. Everything's approved (OT / Leaves / KPIs / adjustments)
2. Set up the Working Days Calendar
3. Check every leaver's exit date
4. Import the attendance

**Generate the payslips — when the check says ready**
5. Tick *Generate Payslips Now* (after *Payslip Readiness* is 🟢)
6. Read the *Card Check Result* & fix any named people
7. Clear every blocker
8. Totals look right

**Approve & pay — one-way**
9. Approve (figures freeze)
10. Mark Paid (emails each employee)
